# Abertura de PR

## Contexto

Branch atual:
!`git branch --show-current`

Branch base detectada:
!`git rev-parse --verify main >/dev/null 2>&1 && echo "main" || (git rev-parse --verify master >/dev/null 2>&1 && echo "master") || echo "(nenhuma branch base — usando HEAD~1)"`

Commits no branch:
!`BASE=$(git rev-parse --verify main >/dev/null 2>&1 && echo "main" || (git rev-parse --verify master >/dev/null 2>&1 && echo "master") || echo "HEAD~1"); git log "$BASE"..HEAD --pretty=format:"%h %s"`

Stats do diff:
!`BASE=$(git rev-parse --verify main >/dev/null 2>&1 && echo "main" || (git rev-parse --verify master >/dev/null 2>&1 && echo "master") || echo "HEAD~1"); git diff "$BASE"...HEAD --stat`

Diff completo:
!`BASE=$(git rev-parse --verify main >/dev/null 2>&1 && echo "main" || (git rev-parse --verify master >/dev/null 2>&1 && echo "master") || echo "HEAD~1"); git diff "$BASE"...HEAD`

## Tarefa

Com base no diff, gere uma **descrição de PR** seguindo o formato padronizado do projeto SafeCover.

### Formato obrigatório

```markdown
## O que muda

[Descrição curta em 1-2 frases — o quê e por quê]

## Mudanças técnicas

- [Lista de mudanças concretas, agrupadas se possível]
- [Arquivos novos / removidos / modificados relevantes]

## Como testei

- [Specs novos ou atualizados]
- [Como rodei localmente — endpoint testado, comando executado]

## Considerações

- [Decisões arquiteturais não óbvias]
- [Trade-offs aceitos]
- [Próximos passos sugeridos, se houver]

## Checklist

- [ ] `bundle exec rspec` verde
- [ ] `bundle exec rubocop` sem ofensas
- [ ] PII mascarada em todas as respostas API tocadas
- [ ] Sem `where("#{var}")` interpolado
- [ ] Migration (se houver) é reversível
- [ ] CLAUDE.md atualizado se mudou convenção
```

## Regras

- **Linguagem:** PT-BR (mensagens para humanos do time)
- **Tom:** profissional, sem hype ("simplifica", "melhora" — não "revoluciona")
- **Bullets curtos**, no máximo 1 linha cada
- **Sem emojis** (mantenha sóbrio)
- **Sem assinatura "Generated by Claude"**

## Não inclua

- Lista exaustiva de cada linha do diff (não é changelog auto-gerado)
- Comentários sobre o processo ("Conforme conversado com X")
- Decisões que ainda estão em aberto (escreva tudo como decidido)

Apresente apenas a **descrição final do PR**, pronta para copiar e colar.
